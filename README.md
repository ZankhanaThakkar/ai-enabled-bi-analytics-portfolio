# AI-Enabled Executive Finance KPI Dashboard

## Overview
This project demonstrates an executive finance dashboard built to monitor revenue, cost, margin, billing accuracy, and reporting automation impact.

## Business Problem
Finance leadership needed a scalable dashboard to reduce manual reporting, improve KPI visibility, and support faster decision-making.

## Solution
Built an executive BI dashboard with KPI cards, financial trends, regional performance views, billing error tracking, and AI-assisted insight summaries.

## KPIs
- Total Revenue
- Total Cost
- Gross Margin %
- Billing Error Rate
- Manual Hours Saved
- Report Run Time Reduction %

## Tools
Power BI / Tableau, Excel, SQL-ready data model, AI-assisted insight generation

## Business Impact
- Improved executive visibility into financial performance
- Reduced manual reporting effort
- Enabled faster month-end review
- Created a reusable self-service BI framework
